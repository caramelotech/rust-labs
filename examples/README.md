Este diretório reúne exemplos de código e projetos já implementados para acompanhar o conteúdo do Rust Labs.

## Exemplos disponíveis

| ------------------------------------ | --------------------------------------- |

## Como usar

1. Escolha um exemplo implementado
2. Leia o README do exemplo
3. Entre na pasta do exemplo e execute com `cargo run`
4. Modifique, teste e experimente variações

Cada exemplo é um projeto Cargo independente, com seu próprio `Cargo.toml`.
