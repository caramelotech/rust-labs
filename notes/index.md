# Rust Labs

Base de conhecimento sobre **Rust** do Caramelo Tech - uma linguagem que combina desempenho, segurança de memória e um compilador que ensina enquanto ajuda. Sua jornada com Rust começa aqui.

## O que você vai encontrar

- **Fundamentos** - seus primeiros passos com Rust: preparar o ambiente com `rustup` e Cargo, entender o que é a linguagem e escrever os primeiros programas. É por aqui que se começa.
- **Prática** - exercícios e projetos para colocar a mão no código e fixar o que foi estudado.
- **Roadmap** - a trilha de estudos de Rust, do primeiro programa à produção, para você saber o que estudar e em que ordem.
- **Recursos** - materiais externos para aprofundar cada assunto.

Navegue pelas seções na barra lateral. Se está começando, comece por Fundamentos.

## Além das notas

O repositório [rust-labs](https://github.com/caramelotech/rust-labs) também contém exemplos de código prontos para executar na pasta `examples/`.
