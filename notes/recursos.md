## Dicas de Uso

1. **Comece pelo livro oficial** - ele foi feito para quem nunca viu Rust
2. **Faça os Rustlings junto com o livro** - cada capítulo tem exercícios correspondentes
3. **Leia as mensagens do compilador** - elas são parte do material de estudo
4. **Escreva testes desde o primeiro dia** - `cargo test` já vem pronto para uso
5. **Construa projetos** - CLIs pequenas são ótimas para fixar ownership e tratamento de erros
